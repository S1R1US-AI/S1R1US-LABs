Why Discord + GitHub Discussions

Future features and upgrades should be openly debated on Discord and the GitHub Discussion board. Together they improve the project by:

  • Ideas — capture proposals early, before they harden into code.
  • RFCs — structure larger changes with written review.
  • Design debate — stress-test UX, APIs, and paper-desk locks in public.
  • Contributor onboarding — help new builders find context and mentors.
  • White-label integration talk — discuss how partners embed or rebrand studio surfaces without forking blindly.
