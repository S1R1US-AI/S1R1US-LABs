2. What Jev is (official · attributed)

Jev is TypeSafe AI’s first public System One model: a typed decision layer that returns probabilities and confidence software can act on. It sits beside a large language model — not as a chat replacement.

The pattern is straightforward: capture state, ask typed questions the software can act on, then let deterministic code enforce exact rules. Product vocabulary stays with TypeSafe AI; this page attributes rather than redefines.

Secondary product surfaces (for later reading): thejevai.com · jev-model · docs.

3. What “Jev Engineering” names (discipline)

Jev Engineering is a community / craft name for the software-engineering decision layer: the LLM writes, the typed model decides, and code enforces exact rules. Think of three tiers — free text, judgment calls, and hard exact rules — and keep each in its lane.

Primary discipline explainer: madewithjev.com/what-is-jev-engineering. Discipline naming is distinct from TypeSafe product headwords; linking that phrase does not transfer ownership of TypeSafe marks, and this page does not claim Made with Jev as S1R1US IP.

D) Brain metaphor · Neural Network · consciousness triad (distinct)

15. Governance & Patch Gate (preview)

Patch Gate is the research preview of how a proposed change would move through the Soft-Launch Path as software engineering — the same unified design strategy, drawn as a gate flow instead of a hub ring.

Patch Gate flow

  1. Proposed change — a patch, copy edit, or research claim enters the gate.
  2. Hard rules (no model) — deterministic checks run first. Jev stays outside the live app code. No stand-in OpenJev. Hard rules run before any model scores a patch.
  3. Scan runtime — visitor-safe security / standards scan against Soft locks Present and cite-pack fences.
  4. Optional typed score — only after hard rules clear may a typed decision-layer score (Jev Engineering craft) be requested. Preview posture; not live SoT.
  5. Outcomes — HOLD · Outer gate clear (Desk Steward / Sensei / human APPROVE) · or FAIL.
